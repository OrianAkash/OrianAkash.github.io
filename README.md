# Akash – portfolio

**Live site:** https://orianakash.github.io/

My portfolio as a C++ game and engine programmer, studying Computer Science
(Interactive Media and Game Development) at SIT × DigiPen Singapore.
It covers 7 projects, including Ember's Escape (custom C++ engine, Team Lead)
and Atelier3D (C++20 engine, audio and physics).

Built from scratch in plain HTML, CSS and JavaScript – no framework,
no build step – and hosted on GitHub Pages.

## What's inside
- `index.html` – all page content
- `css/style.css` – colours, type and layout
- `js/main.js` – light/dark toggle, project filter, heat-warning demo, video reels, copy-email button

## Run it locally
Open `index.html` in any browser.
